# Embryo Web Server

Embryo Web Server is Embryo-Zero's fork of [caddy](https://github.com/caddyserver/caddy) (7ce9f08, commit 7ce9f08). It does web server with automatic HTTPS.

- Our changes live on the `embryo` branch. The original license files (LICENSE) are unchanged.
- Legal notes: LEGAL.md. Dated list of our changes: CHANGES-EMBRYO.md.
